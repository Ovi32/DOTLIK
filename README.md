# Dotlik IT — Vercel-ready website

This is a clean Next.js recreation based on the public structure/content of https://dotlik.vercel.app/.

## Deploy free on Vercel
1. Create a GitHub repository and upload these files.
2. Import the repository into Vercel.
3. Framework: Next.js (auto-detected).
4. Click Deploy. No paid server is required for this static/Next.js site.

The contact form uses the visitor's email client via `mailto:`; for a real server-side contact form, connect an email service later.
